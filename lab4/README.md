# ЛР 4

Эта папка содержит лабораторную работу 4: формирование изображения методом трассировки путей.

Программа строит изображение 3D-сцены с глобальным освещением. Геометрия задается треугольной сеткой, материалы поддерживают диффузное и зеркальное отражение, источники света являются протяженными. Для ускорения используется BVH, тайловый рендер и параллельная обработка.

## Файлы

- `lab4.py` - основной path tracer, CLI и графический интерфейс;
- `scenes.py` - описание сцен `gallery`, `triangle_disco`, `cornell`;
- `лаб4мои.docx` - отчет в формате Word;
- `лаб4мои.pdf` - отчет в формате PDF;
- `lab4_render.png` - пример результата рендеринга.

## Как запустить GUI

Из папки `lab4`:

```bash
python3 lab4.py --gui
```

Или без параметров:

```bash
python3 lab4.py
```

В графическом интерфейсе можно выбрать сцену, разрешение, число лучей на пиксель, глубину пути, число потоков, размер тайла, экспозицию и гамму. Во время расчета отображается live preview.

## Как запустить CLI

Быстрый тест:

```bash
python3 lab4.py --cli --width 160 --height 160 --samples 2 --depth 4 --scene gallery --png
```

Рендер сцены из отчета:

```bash
python3 lab4.py --cli --width 500 --height 500 --scene triangle_disco --samples 30 --depth 8 --light-samples 4 --workers 9 --tile-size 32 --exposure 0.55 --gamma 2.2 --seed 20260525 --png
```

По умолчанию результат сохраняется в `lab4_render.ppm`. При флаге `--png` рядом также создается `lab4_render.png`.

## Основные параметры CLI

- `--scene` - сцена: `gallery`, `triangle_disco`, `cornell`;
- `--width`, `--height` - разрешение изображения;
- `--samples` - число лучей на пиксель;
- `--depth` - максимальная глубина пути;
- `--light-samples` - число выборок прямого света на попадание;
- `--workers` - число процессов, `0` означает автоматический выбор;
- `--tile-size` - размер тайла для параллельного рендера;
- `--output` - путь к выходному PPM-файлу;
- `--png` - дополнительно сохранить PNG.

## Примечание по времени рендера

Path tracing является методом Монте-Карло, поэтому увеличение `--samples`, `--depth` и `--light-samples` улучшает качество, но увеличивает время расчета. Для быстрых проверок лучше использовать маленькое разрешение и 1-4 луча на пиксель.
