# Лабораторная работа 2

## Тема
Расчет интеграла функции на заданном промежутке методом Монте-Карло.

## Цель работы
Изучить базовые методы Монте-Карло для численного интегрирования функции на заданном интервале, сравнить точность разных способов выборки и оценить погрешность результата.

## Задание
Задана функция:

`f(x) = x^2`

Интервал интегрирования:

`[2, 5]`

Необходимо вычислить интеграл:

1. Аналитически.
2. Простым методом Монте-Карло.
3. Методом Монте-Карло со стратификацией с шагом `1` и `0.5`.
4. Методом Монте-Карло с выборкой по значимости для `p(x) ~ x`, `p(x) ~ x^2`, `p(x) ~ x^3`.
5. Методом многократной выборки по значимости для `p1(x) ~ x` и `p2(x) ~ x^3`.
6. Методом русской рулетки для `R = 0.5`, `R = 0.75`, `R = 0.95`.

Расчет выполняется для `N = 100`, `1000`, `10000`, `100000`.

## Аналитическое решение
Точный интеграл:

`I = integral from 2 to 5 of x^2 dx`

Первообразная функции `x^2` равна:

`x^3 / 3`

Тогда:

`I_true = (5^3 - 2^3) / 3 = (125 - 8) / 3 = 39`

Истинное значение интеграла:

`I_true = 39`

## Теоретическая часть

### Общая идея метода Монте-Карло
В пособии `3275.pdf` метод Монте-Карло рассматривается как способ вычисления результата на основе случайных или псевдослучайных чисел. Для интегрирования это означает, что вместо полного анализа всей функции берется набор случайных точек, в этих точках вычисляется функция, а затем по среднему значению строится оценка интеграла.

Для интеграла на произвольном интервале `[a, b]` простая первичная оценка масштабируется на длину интервала:

`I ~= (b - a) * f(xi)`

Если используется `N` независимых выборок, то берется среднее:

`I ~= (b - a) * (1 / N) * sum(f(x_i))`

Главная особенность метода Монте-Карло: результат является случайной оценкой. При увеличении `N` ошибка в среднем уменьшается пропорционально `1 / sqrt(N)`. Поэтому в задании используется оценка:

`Delta I = I_true / sqrt(N)`

### Простое интегрирование методом Монте-Карло
У простого интегрирования методом Монте-Карло есть две распространенные записи.

Первая запись - метод среднего значения функции. Именно он используется в пособии `3275.pdf` в разделе 4.1 и именно он реализован в программе.

В этом методе точки `x_i` выбираются равномерно на интервале `[2, 5]`.

Алгоритм:

1. Сгенерировать `N` случайных точек на `[2, 5]`.
2. Для каждой точки вычислить `f(x_i) = x_i^2`.
3. Найти среднее значение функции.
4. Умножить среднее на длину интервала `5 - 2 = 3`.

Формула:

`I_MC = 3 * average(x_i^2)`

Метод простой, но точки могут случайно распределиться неравномерно. Из-за этого при малом `N` возможна заметная погрешность.

Вторая запись - геометрический метод попаданий под график, который часто приводится в интернете. В нем строится прямоугольник, содержащий график функции, затем генерируются случайные точки `(x_i, y_i)` внутри прямоугольника и считается доля точек, попавших под график.

Для нашей функции `f(x) = x^2` на `[2, 5]`:

`y_min = 0`

`y_max = 25`

`S_rect = (5 - 2) * 25 = 75`

Тогда геометрическая оценка:

`I_hit = (N_hits / N) * S_rect`

Оба подхода являются методами Монте-Карло и оба сходятся к одному интегралу. В отчете и программе выбран метод среднего значения, потому что он прямо соответствует формуле из пособия и обычно эффективнее для одномерного интегрирования: в нем каждая выборка дает численный вклад `f(x_i)`, а не только ответ "попала/не попала".

### Стратифицированная выборка
Стратификация в пособии описывается как разбиение области интегрирования на подобласти. Интеграл считается отдельно в каждой подобласти, а затем частичные оценки складываются.

В работе используются два варианта:

- шаг `1`: интервалы `[2, 3]`, `[3, 4]`, `[4, 5]`;
- шаг `0.5`: интервалы `[2, 2.5]`, `[2.5, 3]`, `[3, 3.5]`, `[3.5, 4]`, `[4, 4.5]`, `[4.5, 5]`.

Формула для суммы по стратам:

`I_strat = sum(width_j * average(f(x_ij)))`

Смысл метода: случайные точки принудительно распределяются по разным частям интервала. Это уменьшает риск, что точки случайно соберутся только в одной области.

В программе число выборок делится между стратами так, чтобы суммарно использовалось ровно `N` выборок.

### Выборка по значимости
В выборке по значимости точки выбираются не равномерно, а по плотности вероятности `p(x)`. В пособии подчеркивается, что такая плотность должна быть нормирована:

`integral p(x) dx = 1`

Также вклад функции нужно делить на плотность, чтобы оценка не стала смещенной:

`I_imp = average(f(x_i) / p(x_i))`

В работе используются плотности вида:

`p_k(x) = C * x^k`

После нормировки на `[2, 5]`:

`p_k(x) = (k + 1) * x^k / (5^(k + 1) - 2^(k + 1))`

Конкретно:

- `p1(x) = 2x / 21`;
- `p2(x) = x^2 / 39`;
- `p3(x) = 4x^3 / 609`.

Для генерации случайных точек используется обратная функция распределения:

`x = (2^(k + 1) + u * (5^(k + 1) - 2^(k + 1)))^(1 / (k + 1))`

где `u` равномерно распределено на `[0, 1]`.

Важный частный случай: при `p(x) ~ x^2` плотность совпадает с формой функции `f(x) = x^2`. После нормировки:

`p2(x) = x^2 / 39`

Поэтому:

`f(x) / p2(x) = x^2 / (x^2 / 39) = 39`

Из-за этого оценка сразу равна истинному интегралу для любого `N`.

### Многократная выборка по значимости
В пособии многократная выборка по значимости применяется тогда, когда трудно подобрать одну хорошую PDF для всей функции. Вместо одной плотности используется несколько плотностей, а их оценки объединяются весами.

В работе используются:

`p1(x) ~ x`

`p2(x) ~ x^3`

Половина выборок берется из `p1`, половина из `p2`. Затем вклад каждой выборки умножается на вес.

Условие несмещенности:

`w1(x) + w2(x) = 1`

Первый вариант весов, сбалансированная эвристика:

`w_i(x) = p_i(x) / (p1(x) + p2(x))`

Второй вариант весов, степенная эвристика с показателем `2`:

`w_i(x) = p_i(x)^2 / (p1(x)^2 + p2(x)^2)`

Итоговая оценка:

`I_MIS = average(w1 * f(x) / p1(x)) + average(w2 * f(x) / p2(x))`

Смысл метода: разные плотности могут лучше работать в разных областях, а веса позволяют объединить их без смещения результата.

### Русская рулетка
Русская рулетка в пособии описывается как вероятностное отсечение. В задачах глобального освещения она обычно нужна для завершения бесконечной рекурсии, но в этой лабораторной она применяется к обычному интегралу как демонстрация метода.

В работе используется вероятность сохранения вклада `R`.

Если вклад сохраняется:

`contribution = (b - a) * f(x) / R`

Если вклад отбрасывается:

`contribution = 0`

Такой метод остается несмещенным, потому что деление на `R` компенсирует вероятность отброса. Но дисперсия становится больше: чем меньше `R`, тем чаще вклад равен нулю и тем сильнее разброс результата.

## Анализ результатов
Все методы оценивают один и тот же интеграл, поэтому результаты должны стремиться к `39`.

Простой метод Монте-Карло дает корректную несмещенную оценку, но результат зависит от случайного расположения точек. При увеличении `N` погрешность обычно уменьшается.

Стратификация делает выборку более равномерной по интервалу. В таблицах видно, что стратифицированные варианты часто дают меньшую ошибку, чем простой метод, особенно на средних значениях `N`.

Выборка по значимости работает лучше, когда PDF похожа на подынтегральную функцию. Самый показательный случай - `p(x) ~ x^2`: результат равен `39` при любом `N`, потому что PDF совпадает с формой функции.

Многократная выборка по значимости дает устойчивые результаты за счет объединения двух PDF. Вес `p/(p1+p2)` соответствует сбалансированной эвристике, а вес с квадратами соответствует степенной эвристике с показателем `2`.

Русская рулетка сохраняет математическое ожидание, но увеличивает разброс. Поэтому при малом `R` возможны большие отклонения, особенно при небольшом `N`.

## Что могут спросить на защите
1. Что такое метод Монте-Карло?

Это численный метод, где результат оценивается по случайным выборкам. В этой лабораторной случайно выбираются точки `x`, считается `f(x)`, а затем строится приближенный интеграл.

2. Почему интеграл равен `39`?

Потому что `integral x^2 dx = x^3 / 3`, а на `[2, 5]` получается `(125 - 8) / 3 = 39`.

3. Почему в простом Монте-Карло нужно умножать на длину интервала?

Среднее значение `f(x)` дает среднюю высоту графика, а интеграл равен площади. Поэтому среднюю высоту нужно умножить на ширину интервала.

4. Почему ошибка Монте-Карло убывает медленно?

Для независимых случайных выборок стандартная ошибка убывает как `1 / sqrt(N)`. Чтобы уменьшить ошибку в 10 раз, нужно примерно в 100 раз больше выборок.

5. Что такое страта?

Страта - это часть области интегрирования. В этой работе это маленький подынтервал внутри `[2, 5]`.

6. Зачем нужна стратификация?

Чтобы случайные точки не собирались неудачно в одной части интервала. Каждая страта получает свои выборки, поэтому покрытие интервала становится равномернее.

7. Что такое PDF?

PDF - это функция плотности вероятности. Она задает, насколько часто случайная точка выбирается около данного `x`.

8. Почему PDF нужно нормировать?

Потому что интеграл плотности вероятности по всей области должен быть равен `1`.

9. Почему при выборке по значимости вклад делится на `p(x)`?

Если мы чаще выбираем одни области и реже другие, без деления на `p(x)` результат был бы смещен. Деление компенсирует неравномерный выбор точек.

10. Почему `p(x) ~ x^2` дает нулевую ошибку?

Потому что `f(x) = x^2`, а нормированная плотность `p2(x) = x^2 / 39`. Тогда `f(x) / p2(x) = 39` для любой точки.

11. Что такое многократная выборка по значимости?

Это способ использовать несколько разных PDF и объединить их оценки с весами. Главное условие: веса должны суммироваться в `1`.

12. Чем отличаются два варианта весов MIS?

Первый вариант `p/(p1+p2)` - сбалансированная эвристика. Второй вариант с квадратами сильнее выделяет PDF, которая в данной точке имеет большее значение.

13. Что делает русская рулетка?

Она случайно отбрасывает часть вкладов. Если вклад не отброшен, он делится на вероятность сохранения `R`.

14. Почему русская рулетка остается несмещенной?

Потому что сохраненный вклад делится на `R`, и это компенсирует вероятность его сохранения.

15. Почему русская рулетка увеличивает дисперсию?

Потому что часть вкладов становится нулевой, а оставшиеся вклады становятся больше из-за деления на `R`. Разброс значений растет.

16. Почему результаты не обязаны строго улучшаться в каждой строке при росте `N`?

Потому что это случайный метод. В среднем ошибка уменьшается, но конкретный запуск может дать локальное отклонение.

17. Зачем в программе `RANDOM_SEED`?

Чтобы генератор псевдослучайных чисел каждый раз выдавал одну и ту же последовательность. Это делает таблицы воспроизводимыми.
