# Теория к ЛР2

## Суть работы
В лабораторной работе нужно вычислить интеграл функции:

`f(x) = x^2`

на интервале:

`[2, 5]`

Точное значение интеграла:

`I_true = integral from 2 to 5 of x^2 dx = (5^3 - 2^3) / 3 = 39`

Дальше это же значение оценивается разными методами Монте-Карло. Все методы должны в среднем сходиться к `39`, но делают это с разной погрешностью.

## Что такое метод Монте-Карло
Метод Монте-Карло - это численный метод, основанный на случайных или псевдослучайных выборках.

Для интегрирования идея такая:

1. Берем случайные точки.
2. Считаем значение функции в этих точках.
3. По среднему значению строим приближение интеграла.

Чем больше выборок `N`, тем в среднем меньше ошибка. Для обычного Монте-Карло стандартная ошибка убывает примерно как:

`1 / sqrt(N)`

Поэтому увеличение `N` в 100 раз обычно уменьшает ошибку примерно в 10 раз.

## Простое интегрирование Монте-Карло
Есть две распространенные формы простого Монте-Карло.

### Метод среднего значения
Именно этот метод используется в нашей программе и в пособии `3275.pdf`.

Точки `x_i` выбираются равномерно на `[a, b]`.

Формула:

`I ~= (b - a) * (1 / N) * sum(f(x_i))`

Для нашей функции:

`I ~= 3 * average(x_i^2)`

Плюс метода: каждая выборка дает численный вклад `f(x_i)`.

### Геометрический метод попаданий
Этот вариант часто показывают в интернете.

Строится прямоугольник, содержащий график функции. Потом генерируются случайные точки `(x_i, y_i)` внутри прямоугольника и считается, сколько точек попало под график.

Формула:

`I ~= (N_hits / N) * S_rect`

Для `f(x) = x^2` на `[2, 5]` можно взять:

`y_min = 0`

`y_max = 25`

`S_rect = (5 - 2) * 25 = 75`

Оба подхода правильные, но в работе выбран метод среднего значения, потому что он лучше подходит для дальнейших методов: стратификации, выборки по значимости и MIS.

## Стратификация
Стратификация - это разбиение интервала на части, которые называются стратами.

В работе используются:

- шаг `1`: `[2, 3]`, `[3, 4]`, `[4, 5]`;
- шаг `0.5`: `[2, 2.5]`, `[2.5, 3]`, `[3, 3.5]`, `[3.5, 4]`, `[4, 4.5]`, `[4.5, 5]`.

В каждой страте отдельно считается интеграл обычным Монте-Карло, потом результаты складываются:

`I_strat = sum(width_j * average(f(x_ij)))`

Зачем это нужно:

- точки распределяются по интервалу равномернее;
- уменьшается риск случайного скопления точек в одной области;
- дисперсия часто становится меньше, чем у простого Монте-Карло.

## Выборка по значимости
В обычном Монте-Карло точки выбираются равномерно. В выборке по значимости точки выбираются чаще там, где функция дает больший вклад.

Для этого задается плотность вероятности `p(x)`.

Оценка интеграла:

`I ~= (1 / N) * sum(f(x_i) / p(x_i))`

где `x_i` выбираются по плотности `p(x)`.

Важно:

- `p(x)` должна быть больше нуля там, где `f(x)` не равна нулю;
- интеграл `p(x)` по области должен быть равен `1`;
- вклад делится на `p(x)`, чтобы оценка не стала смещенной.

В работе используются плотности:

- `p(x) ~ x`;
- `p(x) ~ x^2`;
- `p(x) ~ x^3`.

После нормировки:

`p_k(x) = (k + 1) * x^k / (5^(k + 1) - 2^(k + 1))`

Для `p(x) ~ x^2`:

`p2(x) = x^2 / 39`

Тогда:

`f(x) / p2(x) = x^2 / (x^2 / 39) = 39`

Поэтому при `p(x) ~ x^2` результат получается ровно `39` при любом `N`.

## Многократная выборка по значимости
Многократная выборка по значимости используется, когда одной плотности недостаточно или есть несколько хороших вариантов PDF.

В работе используются две плотности:

`p1(x) ~ x`

`p2(x) ~ x^3`

Половина точек берется из `p1`, половина из `p2`. Затем вклады смешиваются с весами.

Главное условие:

`w1(x) + w2(x) = 1`

Первый вариант весов:

`w_i(x) = p_i(x) / (p1(x) + p2(x))`

Это сбалансированная эвристика.

Второй вариант весов:

`w_i(x) = p_i(x)^2 / (p1(x)^2 + p2(x)^2)`

Это степенная эвристика с показателем `2`.

Смысл MIS: разные плотности могут быть полезны в разных частях области, а веса позволяют объединить их без смещения результата.

## Русская рулетка
Русская рулетка - это вероятностное отсечение вклада.

В работе используется вероятность сохранения `R`.

Если вклад сохраняется:

`contribution = (b - a) * f(x) / R`

Если вклад отбрасывается:

`contribution = 0`

Почему метод остается правильным:

сохраненный вклад делится на `R`, поэтому среднее значение компенсирует вероятность отброса.

Почему ошибка может стать больше:

часть вкладов становится нулевой, а оставшиеся становятся больше из-за деления на `R`. Из-за этого растет дисперсия.

Чем меньше `R`, тем больше разброс результата.

В работе используются:

- `R = 0.5`;
- `R = 0.75`;
- `R = 0.95`.

## Погрешности
Абсолютная погрешность:

`abs_error = |I_calculated - I_true|`

Относительная погрешность:

`rel_error = abs_error / I_true`

Оценка погрешности из задания:

`Delta I = I_true / sqrt(N)`

## Что важно сказать на защите
1. Точный интеграл равен `39`, потому что первообразная `x^2` равна `x^3 / 3`.

2. В программе используется метод среднего значения, а не геометрический метод попаданий. Оба являются методами Монте-Карло.

3. Простое Монте-Карло дает несмещенную оценку, но имеет случайный разброс.

4. Стратификация уменьшает вероятность неравномерного расположения точек по интервалу.

5. Выборка по значимости требует нормированной PDF.

6. Деление на `p(x)` нужно, чтобы компенсировать неравномерный выбор точек.

7. `p(x) ~ x^2` дает точный результат, потому что совпадает с формой функции `x^2`.

8. MIS объединяет несколько PDF с весами, причем веса должны суммироваться в `1`.

9. Русская рулетка сохраняет математическое ожидание, но увеличивает дисперсию.

10. `RANDOM_SEED` нужен, чтобы результаты были воспроизводимыми.

## Короткие ответы
**Почему результаты не всегда строго улучшаются при росте N?**  
Потому что метод случайный. В среднем ошибка уменьшается, но отдельный запуск может дать локальное отклонение.

**Почему на графике ошибка для `p(x) ~ x^2` нулевая?**  
Потому что `f(x) / p(x)` становится постоянной величиной `39`.

**Что лучше: простое Монте-Карло или выборка по значимости?**  
Если PDF выбрана удачно, выборка по значимости обычно лучше. Если PDF плохая, она может не дать выигрыша.

**Зачем вообще русская рулетка, если она увеличивает ошибку?**  
В реальных задачах рендеринга она нужна для вероятностного завершения длинных или бесконечных рекурсий. В этой лабораторной она используется как демонстрация метода.
