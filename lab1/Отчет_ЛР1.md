# Лабораторная работа 1

## Тема
Вычисление яркости в точках на поверхности.

## Цель работы
Изучить вычисление освещенности и яркости точек на плоскости треугольника с учетом нескольких точечных источников света и отражательных свойств поверхности.

## Используемые формулы
1. Цветная сила излучения источника:
   `I(RGB, s) = I0(RGB) * cos(theta)`
2. Цветная освещенность точки:
   `E(RGB, PT) = I(RGB, s) * cos(alpha) / R^2`
3. Перевод локальных координат в глобальные:
   `PT = P0 + e1 * x + e2 * y`, где
   `e1 = (P1 - P0) / |P1 - P0|`, `e2 = (P2 - P0) / |P2 - P0|`
4. Нормаль к плоскости:
   `N = ((P1 - P0) x (P2 - P0)) / |(P1 - P0) x (P2 - P0)|`
5. Вектор от источника к точке:
   `s = PT - PL`
6. Вектор от точки к источнику:
   `l = PL - PT`
7. Яркость точки:
   `L(RGB, PT, v) = (1 / pi) * sum(Ei(RGB, PT) * f(RGB, PT, v, si))`
8. BRDF:
   `f(RGB, PT, v, l) = K(RGB) * (kd + ks * (h * N)^ke)`
9. Средний вектор:
   `h = (v + l) / |v + l|`

В работе используется локальная модель отражения Блинн-Фонга: диффузная составляющая берется по ламбертовской модели, а зеркальная рассчитывается через средний вектор `h`.

## Шаги алгоритма
1. По заданным вершинам треугольника вычислить единичные векторы
   `e1 = (P1 - P0) / |P1 - P0|`, `e2 = (P2 - P0) / |P2 - P0|`.
2. Вычислить единичную нормаль к плоскости треугольника
   `N = ((P1 - P0) x (P2 - P0)) / |(P1 - P0) x (P2 - P0)|`.
3. Для каждой локальной точки `(x, y)` вычислить глобальные координаты
   `PT = P0 + e1 * x + e2 * y`.
4. Для каждого источника света вычислить вектор
   `si = PT - PLi`, `li = PLi - PT`, квадрат расстояния `Ri^2 = |si|^2`,
   `cos(alphai) = (li * N) / |li|`, `cos(thetai) = (si * Oi) / |si|`.
5. Для каждого источника определить цветную силу излучения
   `Ii(RGB, si) = I0i(RGB) * cos(thetai)`.
6. Вычислить освещенности от каждого источника
   `Ei(RGB, PT) = Ii(RGB, si) * cos(alphai) / Ri^2`.
7. Для каждого источника вычислить средний вектор
   `hi = (v + li) / |v + li|`.
8. Вычислить отражательную функцию поверхности
   `f(RGB, PT, v, li) = K(RGB) * (kd + ks * (hi * N)^ke)`.
9. Найти итоговую яркость точки
   `L(RGB, PT, v) = (1 / pi) * sum(Ei(RGB, PT) * f(RGB, PT, v, si))`.
