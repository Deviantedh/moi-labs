# Лабораторная работа 3

## Тема
Формирование распределения случайных величин в заданной области определения.

## Цель работы
Изучить методы формирования заданных распределений случайных координат и направлений лучей в пространстве. Проверить корректность полученных распределений численно и графически.

## Задание
Необходимо сформировать по `100000` выборок для четырех случаев:

1. Равномерное распределение точек внутри треугольника, заданного вершинами `V1`, `V2`, `V3`.
2. Равномерное распределение точек внутри круга, заданного центром `C`, радиусом `Rc` и нормалью `N`.
3. Равномерное распределение направлений в пространстве, то есть точек на единичной сфере.
4. Косинусное распределение направлений относительно заданной нормали `N`.

Для каждого случая нужно доказать, что выборки попадают в заданную область и соответствуют нужному закону распределения.

## Входные данные
Треугольник:

- `A = (0.0, 0.0, 0.0)`
- `B = (2.0, 0.0, 0.0)`
- `C = (0.5, 1.8, 0.7)`

Круг:

- центр `C = (-1.0, 0.5, 0.8)`
- нормаль `N = (0.2, -0.3, 1.0)`
- радиус `Rc = 1.2`

Косинусное распределение:

- нормаль `N = (0.0, 0.0, 1.0)`

## Теоретическая часть

### Равномерные точки внутри треугольника
В пособии `3275.pdf` в разделе 4.7.1 описан способ формирования равномерных точек внутри треугольника через выборку в параллелограмме.

Пусть `u` и `v` равномерно распределены на `[0, 1)`. Если выполняется условие:

`u + v <= 1`,

то точка уже лежит внутри треугольника. Если:

`u + v > 1`,

то берутся отраженные координаты:

`u = 1 - u`, `v = 1 - v`.

После этого точка вычисляется по формуле:

`P = A + u * (B - A) + v * (C - A)`.

Такой способ не отбрасывает выборки: из `100000` случайных пар получается ровно `100000` точек внутри треугольника.

### Равномерные точки внутри круга
В разделе 4.7.1 пособия `3275.pdf` для круга приведен метод через полярные координаты. Если выбрать радиус как `r = Rc * sqrt(xi)`, а угол как `phi = 2 * pi * eta`, то распределение будет равномерным по площади круга.

Формулы:

`r = Rc * sqrt(xi)`,

`phi = 2 * pi * eta`,

`P = C + r * cos(phi) * T + r * sin(phi) * B`,

где `T` и `B` - два единичных взаимно перпендикулярных вектора в плоскости круга, а нормаль к этой плоскости равна `N`.

Квадратный корень нужен потому, что площадь кольца растет пропорционально радиусу. Если выбирать `r` равномерно напрямую, точки сильнее скапливались бы около центра.

### Равномерные направления на сфере
В разделе 4.7.2 пособия `3275.pdf` равномерное распределение на сфере строится через равномерное распределение высоты `z` и азимутального угла `phi`.

Формулы:

`z = 1 - 2 * xi`,

`phi = 2 * pi * eta`,

`x = sqrt(1 - z^2) * cos(phi)`,

`y = sqrt(1 - z^2) * sin(phi)`.

Итоговое направление:

`omega = (x, y, z)`.

При таком способе координата `z` имеет постоянную плотность на `[-1, 1]`, поэтому точки равномерно покрывают единичную сферу.

### Косинусное распределение направлений
В разделе 4.7.4 пособия `3275.pdf` рассматривается ламбертовская модель, где интенсивность пропорциональна `cos(theta)`. В `3281.pdf` этот же косинус появляется при выводе закона освещенности: отклик поверхности зависит от угла между нормалью и направлением падающего потока.

Нормированная плотность по телесному углу на верхней полусфере:

`p(omega) = cos(theta) / pi`.

Коэффициент `1 / pi` нужен, потому что `integral over hemisphere cos(theta) d omega = pi`.

Для формирования cosine-weighted направления используется равномерная точка на единичном круге:

`r = sqrt(xi)`,

`phi = 2 * pi * eta`.

Затем строится локальное направление:

`omega_local = (r * cos(phi), r * sin(phi), sqrt(1 - r^2))`.

После перехода в систему координат с осью `N` получается направление в пространстве. Для величины:

`mu = cos(theta) = dot(omega, N)`

теоретическая плотность равна:

`p(mu) = 2 * mu`, где `mu` лежит на `[0, 1]`.

## Метрики проверки

В работе используются следующие метрики:

- `Inside ratio` - доля точек или направлений, которые удовлетворяют ограничениям области.
- `Constraint error` - средняя ошибка ограничения: отклонение от плоскости для треугольника и круга, отклонение длины от единицы для направлений.
- `Mean error` - отклонение среднего значения от теоретического: центра масс для треугольника и круга, нулевого среднего направления для сферы, значения `2/3` для `mu` в косинусном распределении.
- `Uniformity score` - среднее отклонение эмпирической плотности от теоретической или относительный разброс точек по одинаковым частям фигуры.

Для треугольника дополнительно используются 8 одинаковых прямоугольников в локальных координатах. Для круга используются 8 равных секторов по углу `phi`. Если распределение равномерное, то в равных по площади областях число точек должно быть близким к ожидаемому среднему.

Для сферы используются 8 равных частей: 2 интервала по координате `z` и 4 сектора по азимуту `phi`. Для косинусного распределения используются интервалы по `mu = cos(theta)`, но ожидаемое число точек в них не одинаковое, а вычисляется по теоретической плотности `p(mu) = 2mu`.

## Проверка распределений

### Треугольник
Все точки должны удовлетворять условиям:

`u >= 0`, `v >= 0`, `u + v <= 1`.

Кроме этого, точки должны лежать в плоскости треугольника. Равномерность проверяется по 8 одинаковым прямоугольникам в локальных координатах `(u, v)`.

Ожидаемое число точек в каждом прямоугольнике:

`N_expected = N * S_rect / S_triangle_uv`.

В локальных координатах площадь треугольника равна `0.5`, площадь каждого проверочного прямоугольника равна `0.2 * 0.2 = 0.04`, поэтому:

`N_expected = 100000 * 0.04 / 0.5 = 8000`.

### Круг
Все точки должны удовлетворять условию:

`x^2 + y^2 <= Rc^2`.

Также проверяется отклонение от плоскости круга. Равномерность проверяется по 8 равным секторам в локальных координатах круга.

Для каждого сектора угол равен `2pi / 8`, поэтому площадь сектора:

`S_sector = S_circle / 8`.

Ожидаемое число точек в каждом секторе:

`N_expected = N * S_sector / S_circle = N / 8`.

При `N = 100000` получается `12500` точек на сектор.

### Сфера
Для всех направлений проверяется длина:

`|omega| = 1`.

Равномерность дополнительно показывается по гистограмме координаты `z`. Теоретическая плотность для равномерной сферы:

`p(z) = 0.5` на интервале `[-1, 1]`.

В таблице сфера разбивается на 8 равных частей: 2 интервала по `z` и 4 сектора по `phi`. Для равномерного распределения на сфере элемент площади можно записать как:

`dS = dphi * dz`.

Поэтому одинаковая ширина по `z` и одинаковая ширина по `phi` дают одинаковые площади частей. Ожидаемое число точек в каждой части:

`N_expected = N / 8 = 12500`.

### Косинусное распределение
Для всех направлений проверяется:

`|omega| = 1`,

`dot(omega, N) >= 0`.

Затем строится гистограмма величины `mu = cos(theta)`. Теоретическая плотность:

`p(mu) = 2 * mu`.

В таблице косинусное распределение разбивается на 20 равных интервалов по `mu`. Ожидаемое число точек для интервала `[mu_left, mu_right]` считается не как `N / 20`, а через интеграл плотности:

`N_expected = N * integral from mu_left to mu_right of 2mu dmu`.

После интегрирования:

`N_expected = N * (mu_right^2 - mu_left^2)`.

## Доказательство корректности распределений

Корректность распределений доказывалась двумя способами: аналитически через используемые формулы генерации и численно через метрики, таблицы и графики.

### Треугольник
Для треугольника использовался метод отражения из раздела 4.7.1 пособия `3275.pdf`. Сначала формируются две равномерные величины `u` и `v` на `[0, 1)`, то есть точка в параллелограмме, построенном на сторонах треугольника. Если `u + v > 1`, точка отражается заменой:

`u = 1 - u`, `v = 1 - v`.

После этого всегда выполняются условия:

`u >= 0`, `v >= 0`, `u + v <= 1`.

Эти условия являются барицентрическим критерием принадлежности треугольнику. Равномерность сохраняется, потому что исходное распределение в параллелограмме равномерное, а отражение второй половины параллелограмма внутрь треугольника сохраняет площади.

Численно это проверялось по доле точек внутри области, отклонению от плоскости треугольника, близости среднего значения к центроиду `(A + B + C) / 3` и по числу точек в 8 одинаковых прямоугольниках. Для каждого прямоугольника дополнительно считается ожидаемое среднее `8000` точек и ошибка `N_real - N_expected`.

### Круг
Для круга использовались полярные координаты из раздела 4.7.1 пособия `3275.pdf`:

`r = Rc * sqrt(xi)`, `phi = 2 * pi * eta`.

Квадратный корень появляется из функции распределения радиуса. Для равномерного распределения по площади вероятность попасть внутрь радиуса `r` должна быть равна отношению площадей:

`P(r) = pi * r^2 / (pi * Rc^2) = r^2 / Rc^2`.

Отсюда по методу обратной функции:

`xi = r^2 / Rc^2`, значит `r = Rc * sqrt(xi)`.

Все точки лежат внутри круга, потому что `0 <= r <= Rc`, следовательно `x^2 + y^2 <= Rc^2`. Для произвольной ориентации круга строится локальный ортонормированный базис в плоскости, перпендикулярной нормали `N`.

Численно проверялись принадлежность кругу, отклонение от плоскости круга, близость среднего значения к центру `C` и равномерность по 8 равным секторам. Для каждого сектора ожидаемое среднее равно `N / 8`, то есть `12500` при `N = 100000`.

Сектор определяется по локальному углу точки:

`phi = atan2(y, x)`.

Если `phi < 0`, к нему добавляется `2pi`, чтобы получить диапазон `[0, 2pi)`. После этого весь круг делится на интервалы угла: `[0;45)`, `[45;90)`, ..., `[315;360)` градусов.

### Сфера
Для равномерного распределения на сфере использовался метод из раздела 4.7.2 пособия `3275.pdf`: равномерно выбираются высота `z` и азимутальный угол `phi`.

`z = 1 - 2 * xi`, `phi = 2 * pi * eta`.

Затем направление строится как:

`omega = (sqrt(1 - z^2) * cos(phi), sqrt(1 - z^2) * sin(phi), z)`.

Равномерность объясняется тем, что элемент площади сферы через высоту записывается как:

`dS = dz * dphi`.

Поэтому равномерные `z` на `[-1, 1]` и `phi` на `[0, 2pi)` дают равномерное распределение по поверхности сферы. Длина направления равна единице, так как:

`x^2 + y^2 + z^2 = (1 - z^2) + z^2 = 1`.

Численно проверялись единичная длина всех направлений, близость среднего направления к нулю и гистограмма `z`, которая должна совпадать с теоретической плотностью `p(z) = 0.5`. Таблица по сфере строится по 8 равным частям: 2 интервала по `z` и 4 сектора по `phi`. Ожидаемое среднее в каждой части равно `12500`.

### Косинусное распределение
Для косинусного распределения использовалась идея распределения Ламберта из раздела 4.7.4 пособия `3275.pdf`, где интенсивность пропорциональна:

`I(theta) = cos(theta)`.

В программе сначала равномерно выбирается точка на единичном диске:

`r = sqrt(xi)`, `phi = 2 * pi * eta`.

Затем она поднимается на верхнюю полусферу:

`omega_local = (r * cos(phi), r * sin(phi), sqrt(1 - r^2))`.

Такой способ дает косинусное распределение, потому что ортогональная проекция полусферы на диск вносит множитель `cos(theta)`: равномерность на диске соответствует плотности на полусфере, пропорциональной `cos(theta)`.

В программе для проверки используется `mu = cos(theta) = dot(omega, N)`. Так как `d omega = dphi dmu`, плотность для `mu` получается интегрированием по азимуту:

`p(mu) = integral from 0 to 2pi of mu / pi dphi = 2mu`.

Для проверки используется величина:

`mu = cos(theta) = dot(omega, N)`.

Здесь `theta` - это угол между направлением `omega` и нормалью `N`, а не угол между направлением и плоскостью. Сама величина `mu` тоже не является углом: это косинус угла. Если обозначить угол от плоскости как `alpha`, то `alpha = 90 degrees - theta`, поэтому `mu = cos(theta) = sin(alpha)`.

Для косинусного распределения ее теоретическая плотность равна:

`p(mu) = 2 * mu`, где `0 <= mu <= 1`.

Среднее значение этой величины:

`E[mu] = integral from 0 to 1 of mu * 2mu dmu = 2/3`.

Численно проверялись единичная длина направлений, принадлежность верхней полусфере `dot(omega, N) >= 0`, близость среднего `mu` к `2/3` и совпадение гистограммы `mu` с теоретической прямой `p(mu) = 2mu`. Для каждого интервала по `mu` ожидаемое число точек считается как `N * (mu_right^2 - mu_left^2)`.
